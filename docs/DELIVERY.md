# 전달 안내

KIER 재생에너지 지도 시연본의 실행·데이터·인계 범위를 정리한 문서입니다. 설치와 실행은 [README.md](../README.md)를 보세요.

## 구성

| 구분 | 위치 | 내용 |
|---|---|---|
| 화면 | `web/index.html`, `app.js`, `styles.css` | 지도 화면. DB 접속 코드 없음 |
| 조회 API | `app/api.py` | 읽기 전용. 명세는 [app/API.md](../app/API.md) |
| 지도 서버 | `web/server.mjs` | 화면 제공 + `/api/*` 프록시 |
| 사용법 | [web/README.md](../web/README.md) | 화면 조작과 표기 규칙 |

실행: `python app/api.py` → `node web/server.mjs` → http://127.0.0.1:5057/

## 값의 의미

조회 API는 약 0.2°로 솎은 KIER 원자료에서 **선택 지점에 가장 가까운 격자 값**을 반환합니다. 화면은 사용된 격자 좌표·거리·안내문을 함께 표시합니다(근거: `app/api.py`의 `GRID_NOTE`, `query_point()`).

- 대표 값은 선택 기간 월별 값의 **산술평균**입니다. 누적 발전량이나 월 일수 가중 평균이 아닙니다.
- 하단 7종 요약은 각 자료의 전체 제공 기간 기준이며, 기간 선택 조회와 구분됩니다.
- 30km 이내 격자가 없거나 선택 기간 자료가 없으면 값 대신 상태 안내를 표시합니다.
- 미연동 항목은 `준비 중`, 예시 자료는 `시연용 예시 데이터`로 표시합니다. 화면은 임시 측정값을 만들지 않습니다.
- 천리안2호에는 북한 지역이 포함됩니다. 화면은 API 범위를 그대로 따르며 국경 필터가 없습니다.

## 외부 연결과 인증키

| 연결 대상 | 용도 | 인증 |
|---|---|---|
| 조회 API `/api/datasets`, `/api/point`, `/api/summary` | 상태·값·요약 | 없음(읽기 전용) |
| `https://unpkg.com/leaflet@1.9.4/` | 지도 라이브러리 | 키 없음 |
| `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | 배경 지도 | 키 없음, 지도 내 출처 유지 |
| 공공데이터포털 7종 | 파일·API 원천 | 수집 스크립트(`collect/`)만 사용 |
| 주소 검색(지오코딩) | — | 미사용. 좌표와 주요 도시 15곳만 지원 |

- API 4종 인증키로 시험 호출에 성공했습니다. 키 값은 문서·저장소에 없습니다.
- 인증키 확인과 화면 연동은 별개이며, 연동 상태는 `/api/datasets` 응답을 따릅니다.
- 인증키·DB 접속정보는 별도로 전달하며 `.env`로 설정합니다. 웹 공개 폴더와 저장소에 넣지 않습니다.

## 배포할 때

1. `web/index.html`의 `meta[name="kier-api-base"]`를 배포용 API 주소로 설정합니다(권장: 같은 출처의 `/api/`). 또는 지도 서버의 `KIER_API_BASE`를 씁니다.
2. 웹서버에서 `/api/`를 조회 API에 연결하고 HTTPS를 맞춥니다. 기본값 `127.0.0.1`은 방문자 PC를 가리키므로 외부 배포에 쓰지 않습니다.
3. 지도 CDN·타일 접근을 확인합니다. 운영 전에는 [OSM 타일 사용 정책](https://operations.osmfoundation.org/policies/tiles/)을 확인하고 규모에 맞는 타일 서비스를 정합니다.
4. 소스코드, DB 덤프, 인증키는 구분해서 전달합니다. 접속정보를 웹 공개 폴더에 두지 않습니다.

[확인 불가] 실제 서버 업로드, 운영 HTTPS·외부 접속, DB 덤프 전달은 수행하지 않았습니다.
