# 지도 화면 사용법

지도에서 지점을 고르면 선택한 데이터의 값이 자동으로 조회됩니다. 실행은 [루트 README](../README.md)를 보세요.

## 실행

```powershell
python app/api.py
```
```powershell
node web/server.mjs
```

접속: http://127.0.0.1:5057/

- 화면은 조회 API(`http://127.0.0.1:5056/api/`)만 호출하며 DB에는 연결하지 않습니다.
- API 주소는 `index.html`의 `meta[name="kier-api-base"]` 또는 지도 서버의 `KIER_API_BASE`로 바꿉니다. 같은 출처 `/api/`를 쓰면 지도 서버가 프록시합니다.
- HTTPS 배포에서는 API도 HTTPS 또는 같은 출처 경로여야 합니다. 외부 배포는 검증하지 않았습니다.
- Node 없이 `python -m http.server 5057 --directory web`도 가능하지만 `/api` 프록시는 없습니다.

## 화면 구성

헤더 아래 왼쪽에 조회 메뉴, 나머지는 지도입니다. 선택 지점 결과는 지도 왼쪽 위 카드에 표시됩니다.

## 사용 순서

1. **위치 선택** — 지도 클릭, 좌표 검색(`36.35, 127.38`), 주요 도시, 시도→시군구→읍면동, 행정구역명·코드 검색
2. **데이터 선택** — 여러 개 선택 가능, 선택한 항목을 다시 누르면 해제, 전체 선택 토글 있음
3. **세부 설정** — ‘설정할 데이터’에서 고른 하나의 항목·고도·방위각을 설정(데이터별로 따로 저장)
4. **기준 기간** — 다중 선택에서는 공통 하나. 기간 내 자료가 없으면 ‘기준 날짜에 데이터 없음’

조건을 바꾸면 자동으로 다시 조회하며 별도 조회 버튼은 없습니다. 이전 요청은 취소되고 최신 조건만 반영됩니다.

## 결과 표시

| 선택 | 표시 |
|---|---|
| 1개 | 값 카드 |
| 여러 개 | 데이터·값·단위 표 (행마다 개별 조회, 자료 없음·실패가 다른 행을 막지 않음) |

## 표기 규칙

- 미연동 항목은 `준비 중`, API가 예시로 표시한 자료는 `시연용 예시 데이터`. 임시 측정값은 만들지 않습니다.
- API 연결 실패는 연결 오류로 안내하고, 위치·조건을 바꾸면 기존 결과를 지웁니다.
- 값은 제공 격자·지점의 **최근접 값**이며 선택 좌표의 직접 관측값이 아닙니다. 간격은 데이터마다 다릅니다.
- 풍력 시공간은 10m 풍속 대비 해당 고도의 **풍속가속비율**(풍속 m/s 아님)이며 날짜 구분이 없어 평균을 계산하지 않습니다.
- 인증키·비밀번호는 화면에 포함되지 않습니다.
- 지도 타일은 OpenStreetMap, 라이브러리는 Leaflet 1.9.4(unpkg)라 인터넷이 필요합니다. 지도 로딩에 실패해도 좌표 조회는 됩니다.

## 행정경계

| 항목 | 내용 |
|---|---|
| 파일 | `data/boundaries/`, 코드는 `regions.js`·`region-geometry.js` |
| 기준일 | 2026-10-01 (법정동과 행정동은 다를 수 있음) |
| 표시 | 시군구는 확대 수준 8 이상, 읍면동은 11 이상 (화면에 걸친 시군구가 24개를 넘으면 읍면동 생략) |
| 검색 | 행정구역명·행정코드·좌표. 도로명·번지 검색은 준비 중, 외부 지오코더 미사용 |

지역을 선택하면 경계 안 대표지점으로 이동합니다. **행정구역 전체의 에너지 평균은 계산하지 않습니다.**
